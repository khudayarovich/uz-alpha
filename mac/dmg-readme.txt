UzAlpha — yangi özbek alifbosi uçun klaviaturalar (macOS)
Keyboards for the new Uzbek Latin alphabet (macOS)


ÖRNATIŞ

1. «UzAlpha.bundle» ni şu oynadagi «Keyboard Layouts» papkasi ustiga sudrab
   taşlang (macOS parolingizni söraydi). Şunda klaviaturalar şu Mac'ning
   barça foydalanuvçilari uçun örnatiladi.

   Yoki faqat özingiz uçun: «install.command» faylini işga tuşiring
   (öng tugma → Open).

2. Tizimdan çiqib, qayta kiring.

3. System Settings → Keyboard → Input Sources → Edit → «+» orqali ikkala
   klaviaturani qöşing:

      Özbekça (lotin, avtomatik)   sh → ş, ch → ç, o' → ö, g' → ğ
      Özbekça (lotin, qölda)       ; → ş, ' → ç, [ → ö, ] → ğ, ` → ʼ


INSTALL

1. Drag "UzAlpha.bundle" onto the "Keyboard Layouts" folder in this window
   (macOS asks for your password). That installs the keyboards for every
   user of this Mac.

   Or, for yourself only: run "install.command" (right-click → Open).

2. Log out and log in again.

3. Add both keyboards under System Settings → Keyboard → Input Sources →
   Edit → "+":

      Özbekça (lotin, avtomatik)   automatic: sh → ş, ch → ç, o' → ö, g' → ğ
      Özbekça (lotin, qölda)       manual: ; → ş, ' → ç, [ → ö, ] → ğ, ` → ʼ


To remove: delete UzAlpha.bundle from /Library/Keyboard Layouts
(or from Library/Keyboard Layouts in your home folder).
